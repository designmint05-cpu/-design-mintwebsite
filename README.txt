DESIGN MINT WEBSITE
===================

Files:
- index.html       Main website
- style.css        Layout, colours and responsive design
- script.js        Sidebar navigation, portfolio filters and image viewer
- assets/          Logo and portfolio sample images

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser. Internet is needed for Google Fonts; all portfolio images are local.
3. On mobile, tap the ☰ menu to navigate. Each menu option opens its own page view.
4. Instagram contact link is set to https://www.instagram.com/design_mint.in/

HOW TO PUBLISH WITH GITHUB PAGES
1. Open your existing Design Mint GitHub repository.
2. Upload/replace index.html, style.css, script.js and the entire assets folder in the repository root.
3. Commit the changes.
4. In Settings > Pages, make sure the publishing source is set to the branch and root folder you use.
5. Open the published site and hard-refresh if old images are cached.

NOTES
- The portfolio contains the seven supplied visual samples, including the logo.
- Portfolio artwork is described as concept samples, not verified client work.
- Introductory prices are editable example starting rates. Change them in index.html before publishing if needed.
- The Instagram URL is set to @design_mint.in. No WhatsApp contact button is used.
